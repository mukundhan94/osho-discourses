# The data files

| File | What it holds |
|---|---|
| `data/talks/<year>.csv` | One row per series or group of talks in that year |
| `data/years.json` | Heading, summary and photograph for each year, in page order |
| `data/places.csv` | Town, latitude, longitude (approximate, for the maps) |
| `data/media.csv` | Per series: its wiki page, talk and recording counts, and a listen link. Generated by `make media`; do not edit by hand |
| `data/links.csv` | Links added by hand. See [links.md](links.md) |
| `data/slugs.csv` | The address of each series page. Rows are added by `make slugs` and never changed. See [publishing.md](publishing.md) |
| `india-outline.json`, `world-outline.json` | Simplified map outlines from Natural Earth |

## Columns in `data/talks/<year>.csv`

| Column | Meaning |
|---|---|
| `sort` | Sort key, ISO-like (`1964-06-03`). Add a letter to order rows that share a date. |
| `dates` | Dates as shown on the page. |
| `title` | Series title as romanised on the wiki, or a description for untitled talks. |
| `place` | Place as shown on the page. |
| `towns` | Towns for the map, separated by `;`. Each must exist in `data/places.csv`. |
| `talks` | A number, `at least N`, `about N` or `unknown`. |
| `kind` | `series`, `camp` (meditation camp), `untitled`, `darshan` (darshan diary) or `interview` (press interviews). |
| `unsure` | `y` when the wiki marks the date, place or count as uncertain. |
| `note` | Optional short note shown under the title. |
| `lang` | `hi`, `en`, or empty when mixed or not stated. |

A series that runs across New Year is either split by year, or sits in the year it starts with its full dates in `dates`.

"At least" and "about" in a count are the wiki's own words.

## Add a year

1. Add `data/talks/<year>.csv` with the header above.
2. Add any new towns to `data/places.csv`.
3. Add an entry to `data/years.json` with `id`, `heading` and `lede`.
4. Optionally add a `photo`. The file goes in `assets/img/`, and its credit goes in `assets/img/CREDITS.md`.
5. Run `make media`, `make check` and `make serve`, then look at the page.

A year whose towns all lie in central and northern India gets an India map. Any other year gets a world map fitted to its places. A year with only one place gets a month strip instead of a map.

Two optional keys in `data/years.json` change a year's section: `"route": true` joins the map's places with a dashed line in the order of the rows, and `"closing": [["date", "line"], ...]` replaces the table with those lines (used for 1990).
